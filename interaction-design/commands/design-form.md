# /design-form
Design a form that minimises friction and guides users to successful completion.
## Steps
1. **Structure** — Define field order, grouping, and flow using `form-design` skill.
2. **Cognitive load** — Chunk fields and reduce simultaneous choices using `millers-law` and `hicks-law` skills.
3. **Targets** — Size and position inputs and controls for fast, accurate interaction using `fitts-law` skill.
4. **Error prevention** — Design inline validation and field constraints using `error-handling-ux` skill.
5. **Feedback** — Specify confirmation, progress, and status messages using `feedback-patterns` skill.
6. **Loading** — Design submission and processing states using `loading-states` skill.
## Output
Form specification with field structure, grouping rationale, validation rules, error messages, and submission states.
Consider following up with `/error-flow` to detail the full error handling model.
